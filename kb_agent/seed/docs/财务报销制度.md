# 财务报销管理制度

## 一、适用范围

本制度适用于公司全体在职员工，包括试用期员工与实习生。所有因公发生的费用支出，均须遵循"事前申请、事后报销"的原则，凭合法有效凭证在费用发生之日起 30 个自然日内提交报销单，逾期原则上不予受理。

## 二、差旅住宿标准

差旅住宿标准按出差目的城市分为三档，每晚上限如下：

| 城市档次 | 覆盖城市 | 每晚上限（元） |
| --- | --- | --- |
| 一线城市 | 北京、上海、广州、深圳 | 600 |
| 二线城市 | 杭州、成都、武汉、南京、西安、重庆、苏州、天津 | 450 |
| 其他城市 | 上述以外城市 | 350 |

- 住宿费凭酒店发票实报实销，超出上限部分由员工自行承担。
- 同性别同事同行原则上应合住标准间；因公司安排单住的，须在报销单备注原因。
- 出差期间由客户或合作方安排住宿的，不得重复报销住宿费。
- 住宿标准每年度由财务部结合市场行情复核一次，调整后另行发文。

## 三、差旅交通与补贴

1. 城际交通：3 小时以内优先选择高铁二等座；超过 3 小时或高铁不便的可乘坐飞机经济舱，需提前 3 个工作日报部门负责人审批。
2. 市内交通：出差期间市内公共交通据实报销；网约车单次超过 100 元的需注明事由。
3. 伙食补贴：一线城市 100 元/天，二线城市 80 元/天，其他城市 60 元/天，按实际出差天数计算，无需发票。
4. 出差期间如已由公司统一安排用餐，当天伙食补贴减半。

## 四、业务招待费

业务招待须事前在 OA 提交招待申请，注明客户单位、人数、事由与预算。单次招待人均标准不超过 300 元，超过标准的须由分管副总审批。招待费报销须附消费明细清单，不得以笼统的"餐费"发票报销。

## 五、报销流程

1. 员工在 OA 系统填写报销单，上传发票原件照片或扫描件。
2. 部门负责人审批（3 个工作日内完成）。
3. 财务部初审：核对发票真伪、金额与标准是否符合制度。
4. 财务总监终审：单笔金额超过 5000 元的报销单必须经财务总监签批。
5. 出纳付款：审批通过后每月 10 日、25 日集中付款。

## 六、发票要求

- 发票抬头必须为公司全称，税号准确无误。
- 增值税专用发票须在开票日起 90 日内认证抵扣。
- 电子发票须提供 PDF 原件，不接受截图。
- 连号发票、同一商户大额拆分的发票将被重点核查。

## 七、违规处理

对虚开发票、虚构出差行程、重复报销等行为，一经查实，全额追回款项并按公司奖惩条例处理；情节严重的，解除劳动合同并保留追究法律责任的权利。

## 八、附则

本制度由财务部负责解释，自发布之日起执行。此前发布的同类规定同时废止。
