## 8. 结论与遗留问题

**结论**

- 硬指标达成：越权拦截率 100%（越权泄露 0 次），权限引擎用例全过
- 忠实度 / 拒答 / 引用一致性 / 检索命中率均达到评测文档要求

**遗留问题**

1. 忠实度采用确定性词覆盖，对中文同义改写偏严格；严格口径 73.47% 的未支撑样例
   经复核均为连接语或合理改写。如需更严格结论，建议接入 NLI/LLM-as-judge 复核。
2. 本机未安装 `sentence-transformers`，向量为内置哈希回退实现；
   换用 bge-small-zh-v1.5 后需重跑 L3/L4 以确认指标。
3. 检索评测语料仅 3 篇文档，P@5 上限受限；扩充语料后应重跑 K-E4。
4. 未做并发/压测场景下的权限一致性验证（当前为串行请求）。

## 附：复现方式
